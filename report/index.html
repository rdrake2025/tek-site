Rug report.

TEK samples the latest pump.fun launches and counts what it finds: how many launch, how many come from the same few wallets, how many go quiet within a minute. No coin is named. This is just what launching looks like right now.

How it's counted

Each run takes the most recent launches from pump.fun's public feed, usually around half an hour's worth, and checks a spread of 40 of them on RugCheck. "Went quiet" only counts coins older than ten minutes. A creator flag is RugCheck's label, not proof about any single coin. Numbers move a lot from run to run, so read each one as a snapshot.
